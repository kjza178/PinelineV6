# claude_setup — nguồn của đội subagent dev

Đây là **bản gốc** của `.claude/agents/*.md` và `.claude/commands/*.md` (thư mục `.claude` không ghi được từ công cụ từ xa).

- Cài / cập nhật: chạy `claude_setup\INSTALL.bat` (copy vào `.claude\`).
- Sửa agent: sửa file ở đây rồi chạy lại INSTALL.bat (hoặc sửa thẳng trong `.claude\` rồi chép ngược về đây để không lệch).
- Mô tả đội & lệnh: `docs/brain/agents/dev-team.md`.
