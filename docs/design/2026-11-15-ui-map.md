## 3. Vấn đề rút ra
1. **Hongguo 1 đã ngừng nhưng code còn ép dùng** → Thư viện chưa làm, Mùa mới, gửi tải từ trang Phim, Merge của Studio,
   feeder tự thêm job: đều hỏng. _Đã sửa 2026-11-15 (middleware)._
2. **Ba nơi cài đặt cho cùng một thứ**: `/v6/` Cài đặt · hộp V4 của trang Phim · thanh «cấu hình batch» của Studio (đi
   qua sidecar). Hộp V4 ghi đè khoá AI của `/v6/`.
3. **Phụ thuộc sidecar đã tắt**: Studio (lưu cấu hình, Auto-pilot, Dừng), trang Phim (`/config`, Baike, ảnh AI,
   dừng test kênh) gọi API chỉ sidecar có.
4. **Không có trang chủ thống nhất**: `/` là Studio (cũ), `/v6/` là giao diện mới; mỗi trang một thanh điều hướng.
5. «Thư viện chưa làm» không quét ổ độc lập: phụ thuộc danh sách của Hongguo; bộ tải bằng công cụ khác chỉ hiện nếu
   nằm trong thư mục lưu của Hongguo và đã ghép xong.

## 4. Hướng gom (chờ chủ dự án duyệt)
`/v6/` là app duy nhất; `/` → `/v6/`; Studio dời `/studio` (tạm). Gỡ hộp cài đặt V4. Chuyển vào `/v6/` theo thứ tự:
Nguồn phim (Hongguo 2 + phim trên ổ quét TRỰC TIẾP thư mục thư viện + mùa mới) → Thư viện & đăng YouTube → gộp tập.
Các API chỉ có ở sidecar mà còn cần → chuyển về server.
