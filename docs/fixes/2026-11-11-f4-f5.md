# 2026-11-11 — F4 (services + sidecar thuần) + F5 (render tiến trình con)

Theo thiết kế `docs/design/2026-11-11-v6-architecture.md` mục 5: **F4 C** «services + sidecar thuần — không còn /cmd vòng;
feeder/film_db chạy trong server», **F5 E** «render subprocess — 0 importlib.reload; sửa render có hiệu lực job kế».
(Trước đây dòng «Pha» trong CLAUDE.md ghi đảo F4/F5 — đã sửa theo thiết kế.)

## Triệu chứng
1. **Render trong tiến trình server + reload.** `server._do_render` chạy assemble + `engines.render.run_render` trong
   tiến trình uvicorn và `importlib.reload` 4 module (core.config, engines.subs, engines.render, engines.assemble) mỗi lần mux
   để sửa code có hiệu lực không cần restart. Reload không thay object cũ mà module khác đang giữ (vd `from engines.render_fx
   import …` trong render.py vẫn trỏ bản cũ) → dễ chạy lẫn phiên bản; render nặng giữ GIL trong server.
2. `workers/render_worker.py` (khung F0) gọi `engines.mux.run` — **không tồn tại**; chưa nối vào đâu.
3. **Vòng server → sidecar → server**: tool agent (`agents/agent_core`, chạy TRONG server) `pineline_running_check`,
   `pineline_library`, `pineline_feed` POST `AUTOPILOT_URL/cmd` (mặc định **:8802 = sidecar V2 production** nếu thiếu env)
   → sidecar `handle_command` → `agents.agent_feeder(BASE)` → HTTP ngược về server.
4. **Cổng cứng khi thiếu env**: `agent_tele_cmd` BASE 8801 / CTRL_PORT 8802; `agent_autopilot.DEFAULT_BASE` 8801;
   `agent_tool_loop --base` 8801; `agent_brain(_context)` 8801 + ping sidecar 8802; `agent_hongguo` 8801/8802 (5 chỗ);
   `meta_studio` 8801; `agent_feeder` (dò tiến trình «server.py … 8801», link 8802); `routes_films` 8805/8804;
   `tools/migrate_work` 8801/8802 + `D:\PinelineV2_work` + kill «server.py --port 8801»; `restart_server` 8805/8802 +
   `D:\PinelineV2_tmp\start_8801.py`; `server.py --port` mặc định 8800. tree_audit: 8 WARN cổng.
5. **Sidecar không theo instance**: chạy V6 sidecar không có cách chọn instance; `tg_send` tự đặt `AGENT_TELEGRAM=1`
   → **lách cờ telegram** của instance; sidecar luôn chạy autopilot/feeder/runwatch/film_db/config-live/auto-publish.

## Nguyên nhân
V5 thiết kế sidecar :8802 là tiến trình sở hữu việc nền + Telegram, server chỉ phục vụ HTTP; reload là cách «hot fix» render.
V6 dùng 1 codebase nhiều instance → mọi mặc định phải là cổng của instance, việc nền về server (một tiến trình sở hữu
queue + DB), render ra tiến trình con.

## Sửa
### F5 — render tiến trình con
- **`engines/render_job.py` (mới)**: `do_render(work_dir, …cùng 20 tham số/mặc định với _do_render…, *, hot_reload=False)`
  = thân `_do_render` cũ chuyển nguyên logic (skip khi mux done + dub mới; mark_running; tự Demucs khi chế độ demucs mà chưa
  tách; assemble_fit/naive khi dub thiếu/cũ hơn tts.json, video dài buộc fit; lỗi «Chưa có track giọng Việt»; phase
  hardsub_track/encode; run_render với clamp_zoom/brand…/speed_factor/hardsub_blur; run_render skip → trả done; lỗi →
  mark_failed). Khác: các ghi «phase» dùng `js.set_stage` / `js.mutate` (đọc lại đĩa trong khoá) thay `m.data…; js.persist`
  → **js.persist 98 → 93** (baseline ratchet hạ 93). `importlib.reload` CHỈ trong `if hot_reload:` (đường cũ).
- **`workers/render_worker.py`**: `python -m workers.render_worker <work_dir> <opts_json>` gọi `engines.render_job.do_render`
  (tiến trình mới mỗi job → code render mới nhất, không reload). Giao thức JSON-lines `start/progress/done/error`; dòng
  khác = log (server in `[render:<job>] …`, lọc `_noisy_log`). stdout UTF-8, stdin DEVNULL, env như `_run_engine`
  (PYTHONPATH gốc, PYTHONIOENCODING, bỏ PYTHONHASHSEED hỏng, TQDM_DISABLE).
  `spawn(...)`: luồng phụ hỏi `is_stopped()` mỗi 0,5 s → terminate, quá 3 s → kill (không phụ thuộc worker có in gì).
  `run_job(...)` (phía server, không cần fastapi): đăng ký proc vào `procs` (= `server._PROCS`; proc cũ cùng job còn sống
  → kill), progress → `js.set_stage('mux', progress, cur_text)`, Dừng → `RenderStopped`, lỗi → `js.mark_failed('mux',
  thông báo worker)` + `RuntimeError` (worker cũng tự mark_failed; ghi lại cần khi worker chết không kịp ghi).
  Test: env `PINELINE_RENDER_IMPL=module:func` thay hàm render (chỉ test dùng).
- **`server._do_render`**: dựng kwargs như cũ; cờ instance **`render_subprocess`** bật → `_render_subprocess` (gọi
  `run_job(procs=_PROCS, is_stopped=job in _STOP_JOBS)`, `RenderStopped` → `_Stopped`); tắt → `render_job.do_render(…,
  hot_reload=True)` = hành vi V5. Hai đường cùng một logic. `_HEAVY_ENGINE_SCRIPTS` thêm `render_worker` → `_stop_job` /
  dọn orphan lúc khởi động kill được worker (ngoài `_PROCS`). Nút Dừng: `_stop_job` terminate/kill `_PROCS[job]`
  (= worker) + `_kill_job_children` (ffmpeg theo cwd) + stage running → pending; worker không ghi «failed».
- **Cờ** `render_subprocess`: v6 `true`, test `true`, **prod `false`** (cho tới khi user chạy job thật so output
  in-process vs tiến trình con). Không env (`python server.py`) → tắt (như V5).
- **Còn `importlib.reload` ngoài đường render** (chưa đụng, ghi lại): server.py 4 chỗ (Demucs ×2 ở run_stage/auto,
  clone_tts ×1, translate ×1); `http_routes/routes_hg.py` 43 chỗ (Hongguo — chuyển sang `services/hongguo_flow.bridge()`
  cần chạy thật với Hongguo :8000); `agents/agent_tele_cmd.py` 30 chỗ (route HTTP sidecar). Gate F5 «0 reload ở đường
  render» đạt; gate toàn cục chưa.

### F4 — services + sidecar thuần
- **`core/instance.py`**: `server_port()/server_base()/sidecar_port()/sidecar_url()` — env (PINELINE_BASE/PINELINE_PORT/
  AUTOPILOT_PORT/AUTOPILOT_URL) → instance mặc định (PINELINE_INSTANCE hoặc v6: 8806/8816). **Không bao giờ rơi về
  8801/8802.** `Instance.sidecar_port`; cờ mới `render_subprocess`, `feeder` (flags() + PINELINE_FLAG_*).
- **`services/`** (lớp mỏng, import agents bên trong hàm → `import services.*` không cần fastapi/requests):
  `feeder.py` (running_text, lib_command, feed_command = nhánh /feed chuyển nguyên văn từ sidecar, feeder_loop,
  runwatch_loop), `autopilot.py` (autopilot_loop, config_watch_loop, sync_and_report), `film_db_sync.py` (sync_once, loop),
  `publisher.py` (worker auto-publish chỉ khi cờ auto_publish), `hongguo_flow.py` (khung `bridge()` không reload),
  `background.py` (start/stop các vòng; chờ 15 s để server bind cổng).
- **Bỏ vòng /cmd**: `agent_core._sidecar_cmd` (POST sidecar /cmd) → `_service_cmd` gọi thẳng `services.feeder` trong
  tiến trình server. Sidecar `/running`, `/lib`, `/feed` gọi cùng hàm service. (Hàm service vẫn gọi API của CHÍNH server qua
  HTTP — giữ nguyên code agents; đổi sang gọi hàm là việc sau.)
- **Việc nền trong server**: `server._start_background_services` (startup) — cờ **`feeder`** bật → `services.background.start`
  (autopilot, config-live, runwatch, feeder, film-db; + publisher nếu cờ auto_publish). v6/test `false` (khung, tắt),
  prod `true` (giữ chức năng V2 khi cutover — kiểm ở F6). Notify qua `agent_watch.telegram_send` (tắt khi telegram=false).
- **Sidecar theo instance** (`agents/agent_tele_cmd.py`): `--instance <tên>` → `apply_env` + cập nhật BASE/CTRL_PORT
  (mặc định từ core.instance). Telegram chỉ khi cờ telegram (`_telegram_allowed`; `tg_send` trả False, `telegram_loop`
  không poll, `_ensure_agent_telegram` không tự bật). Có env instance (PINELINE_FLAG_FEEDER) → **không** chạy vòng nền
  (server sở hữu); không env (kiểu V5) → như cũ. Vòng sidecar cũ thành lớp gọi services. `run_sidecar_v6.bat` (mới):
  `python agents\agent_tele_cmd.py --instance v6` → :8816, Telegram tắt, không vòng nền.
- **Cổng cứng → instance**: agent_autopilot, agent_tool_loop, agent_brain, agent_brain_context (khoá ping
  `sidecar_8802` → `sidecar`), agent_hongguo, meta_studio, agent_feeder (dò server theo cổng instance, cả `-m app`),
  routes_films (`_host_fallback`), tools/migrate_work (DST mặc định WORK_DIR, kill theo `--port <instance>`),
  restart_server (PORT/SIDECAR instance; script legacy chỉ qua env `PINELINE_LEGACY_START`), server.py `--port`.
  **Giữ (có lý do)**: `agents/canva_client.py` redirect_uri `…:8802/canva/callback` — phải khớp app Canva đã đăng ký
  (env `CANVA_REDIRECT_URI` ghi đè); text hiển thị «sidecar :8802» trong uploader_settings_api (không phải URL).
- `scripts/tree_audit.py`: thêm `PinelineV6: 8806` vào PORT_OF.
